
# StrikeMobile 🎮

Мобильный 3D-шутер от первого лица, вдохновлённый Counter-Strike 1.6.

## ✨ Возможности
- 🎯 Вид от первого лица (FPS)
- 🤖 Одиночная игра с ботами
- 🔫 Стрельба и перезарядка
- ❤️ Система здоровья
- 🕹️ Сенсорное управление для Android
- 📱 Поддержка архитектуры ARM64

## 🛠️ Технологии
- Godot Engine 4.3
- GDScript
- GitHub Actions для автоматической сборки

## 📦 Сборка APK
1. Открой вкладку **Actions** в репозитории.
2. Выбери workflow **Build Android APK**.
3. Нажми **Run workflow**, если автоматическая сборка ещё не запущена.
4. Дождись завершения сборки.
5. Открой завершённый запуск workflow.
6. Скачай артефакт `StrikeMobile-APK` в разделе **Artifacts**.

## 🚀 Запуск проекта
1. Скачай исходный код репозитория.
2. Открой проект в Godot 4.3.
3. Установи Android Export Templates и настрой Android SDK/JDK.
4. Выбери пресет Android и экспортируй APK.

## ⚠️ Статус проекта
Это ранний прототип. Возможны ошибки, а управление и Android-сборку необходимо протестировать на устройстве.
